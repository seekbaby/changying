## 🚀 飞牛NAS 一键安装

### ⚠️ 前置条件：安装 Docker（只需一次）

飞牛NAS 已内置 Docker 支持，在 **应用中心** 搜索安装即可：

```
飞牛NAS 桌面 → 应用中心 → 搜索 "Docker" → 安装
```

> 💡 你的 NAS 之前已经装过 Docker 和 Docker Compose，跳过此步即可。

### 方式一：自动安装（推荐）

```bash
# 1. 将整个目录上传到 NAS（如 /volume1/docker/changying/）
# 2. 在飞牛NAS中打开 SSH，进入目录
cd /volume1/docker/changying/

# 3. 执行一键安装
chmod +x deploy/install.sh
./deploy/install.sh
```

### 方式二：Docker Compose

```bash
docker compose up -d
```

### 方式三：手动构建

```bash
# ARM64 NAS 上
docker build --platform linux/arm64 -t changying:1.0 .
docker run -d --name changying --restart unless-stopped \
  -p 3000:3000 -v changying_data:/app/data changying:1.0
```

## 🔄 版本更新

```bash
# 1. 将新版本目录上传到 NAS，覆盖旧文件
#    （如通过 SMB 共享或 scp）

# 2. SSH 进入项目目录，执行升级脚本
cd /volume1/docker/changying/
chmod +x deploy/update.sh
./deploy/update.sh
```

升级脚本会自动：**备份数据 → 停旧容器 → 构建新镜像 → 启动新容器**。数据库文件通过 Docker 卷持久化，升级不会丢失任何业务数据。

如果升级失败，脚本会尝试恢复旧容器；数据也有一份备份在 `./changying_backup_日期/` 目录下。回滚只需：

```bash
# 切回旧版本目录
cd /volume1/docker/changying_old/
docker stop changying && docker rm changying
docker compose up -d
```

## ❓ 常见问题

**Q: Docker 能不能一起打包到安装包里？**

不能。Docker 是系统级服务（类似操作系统的服务管理器），必须通过飞牛NAS 的「应用中心」安装。好在飞牛NAS 已经内置支持，应用中心搜 "Docker" 一键安装即可。你的 NAS 之前已经装过了，不需要再装。

**Q: 为什么用 Docker 而不是传统安装包？**

长盈依赖 better-sqlite3（需要编译 C++ 代码）和 Node.js 运行时。Docker 把这些全部封装在一个隔离环境里，确保在任何 NAS 上行为一致，不会出现 ARM/x86 兼容性问题。

**Q: 数据存在哪？删容器会丢吗？**

不会。数据库文件通过 Docker 卷 `changying_data` 持久化在 NAS 物理硬盘上。即使删除容器、重装系统，只要不删这个卷，数据都在。

```bash
# 备份命令
docker cp changying:/app/data ./backup_$(date +%Y%m%d)
```

**Q: 怎么从外网访问？**

方案一：飞牛NAS 自带 FN Connect 远程访问，配合端口转发即可。
方案二：用 Cloudflare Tunnel（免费）穿透，需要域名。
